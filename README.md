## วิธีใช้หลักสูตรนี้

1. เริ่มจาก Part 01 และทำตามลำดับ
2. แต่ละ Part มี:
   - อธิบายแนวคิด
   - Code/Config examples ที่ใช้งานได้จริง
   - Hands-on exercises
   - Mini-project หรือ challenge
3. ทำ exercises ทุกข้อก่อนไป Part ถัดไป

## Prerequisites

- ความรู้พื้นฐาน Linux/Terminal
- มีคอมพิวเตอร์สำหรับ practice
- GitHub account (ฟรี)
